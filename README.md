# 🍽️ منصة MENU IRAQ – نظام SaaS لقوائم الطعام الإلكترونية في العراق

منصة رقمية موحدة مبنية بنظام **Multi-Tenant SaaS** (تطبيق واحد وقاعدة بيانات واحدة تخدم مئات المطاعم)، تمنح كل مطعم في العراق هوية رقمية ورابط منيو سريع ورمز QR مخصص وإرسال طلبات عبر الواتساب.

---

## 🌟 الفكرة الهندسية (Multi-Tenancy Architecture)
بدلاً من بناء موقع منفصل لكل مطعم وتكبد تكاليف خوادم وصيانة باهظة:
1. **نواة برمجية واحدة:** كود واحد يتم تحديثه وتطويره باستمرار.
2. **رابط فريد لكل مطعم:** 
   - `menuiraq.com/baghdad-shawarma`
   - `menuiraq.com/erbil-burger`
   - `menuiraq.com/basra-fish`
3. **عزل البيانات الأمني (Data Isolation):**
   - لكل مطعم معرّف فريد (`restaurant_id`).
   - المنتجات والأقسام والطلبات مفصولة كلياً باستخدام سياسات حماية متقدمة (Row Level Security - RLS).
   - صاحب المطعم لا يرى سوى بيانات مطعمه فقط.
   - المدير العام (Super Admin) يملك السيطرة الشاملة لتفعيل أو تعطيل المطاعم ومتابعة النمو.

---

## 📱 ميزات النظام
- ⚡ **فائق السرعة وخفيف للهواتف:** مصمم خصيصاً لشبكات الإنترنت وسرعات الهواتف في العراق.
- 📲 **طلبات واتساب مباشرة:** سلة التسوق تحسب المجموع بالدينار العراقي (IQD) وتنشئ رسالة واتساب منسقة تتضمن الأصناف والعنوان وملاحظات الزبون بنقرة واحدة.
- 🎨 **قوالب متعددة وتخصيص هوية:** دعم ألوان مختلفة، شعار المطعم، صورة الغلاف، وحالة توفر الوجبات.
- 📷 **رمز باركود QR ذكي:** جاهز للتحميل والطباعة لوضعه على طاولات الصالة.
- 💰 **تكلفة تشغيلية $0:** استخدام خدمات مجانية قوية (React + Supabase Free + GitHub).
